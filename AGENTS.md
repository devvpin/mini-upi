This repository is **Mini-UPI**, a university cryptography project (virtual money only).

Before doing anything:
1. Read `brain/00_MASTER_PROMPT.md`, then the other numbered files in `brain/`.
2. Read `brain/PROGRESS.md` and work **only** on the phase marked `IN PROGRESS`.
3. Follow `brain/08_AGENT_RULES.md`. Stop at the phase gate and report.

Non-negotiables: simulation only, no real payments, no UI kits/templates, no hand-rolled crypto primitives, no secrets in git.
